# College Value Compass

## Overview

College Value Compass is a data analytics project designed to help
students compare colleges based on the value they offer for a
specific major.

The goal is to help students evaluate institutions using factors
such as affordability, graduation outcomes, and post-college earnings.

## Key Questions

- Which colleges offer the strongest value for a selected major?
- How do affordability and career outcomes vary across institutions?
- How do college rankings change based on individual priorities?

## Planned Technology

- Python and pandas for data preparation
- SQL and DuckDB for data analysis
- Power BI for interactive visualization
- U.S. Department of Education College Scorecard data

## Project Status

Initial setup and data exploration.

## Methodology

The project will use transparent metrics and documented assumptions.
Institution-level outcomes will be distinguished from major-specific
outcomes wherever the data allows.

## Limitations

Rankings will depend on the available data, metric definitions,
and selected weighting methodology. Results will not represent a
guarantee of an individual student's future outcomes.
